# Lifeline

This project aims to expand on the existing LoRa Puck guide, to make a pair of fully functioning transmitters that can display messages from the latter via oled, provide accurate GPS location up to 2 meters and even vital info on moisture, temperature and pressure to make an esitmated guess on the weather at the area and relay it.


# Lessons

I LOVED the physics behind the why in the routing it actually linked so well to my own studies, especially the low pass filtering. Despite this being my smallest pcb to date by no means was it the easiest, with cramming as efficiently each component so there was enough room as well as keeping enough space to allow the RF components to work properly and juggle vias everywhere it was a labour.
